# 消化科医疗智能体实施计划索引

本索引将已批准的设计拆成六个可独立验收的阶段。必须按顺序执行；后一阶段不得在前一阶段的验收、临床治理批准和发布记录完成前启动。

| 顺序 | 文档 | 目标 | 退出条件 |
|---|---|---|---|
| 0 | `2026-08-16-phase-0-clinical-governance.md` | 建立临床与数据治理 | 范围、红旗和知识准入已批准 |
| 1 | `2026-08-16-phase-1-secure-foundation.md` | 建立安全、隔离、可观测的服务底座 | 安全与恢复演练通过 |
| 2 | `2026-08-16-phase-2-case-triage.md` | 病例结构化和红旗分诊 | 红旗规则临床验证通过 |
| 3 | `2026-08-16-phase-3-evidence-differential.md` | 受控证据型鉴别诊断 | 每项临床主张可追溯 |
| 4 | `2026-08-16-phase-4-validation-shadow.md` | 离线验证和影子运行 | 达到预先冻结的安全阈值 |
| 5 | `2026-08-16-phase-5-controlled-pilot.md` | 单机构受控试点 | 治理组批准扩大或停止 |

所有阶段遵守同一不可变原则：仅成人消化科门诊；仅腹痛、消化不良和反酸；系统不做自动诊断、处方、检查开立或病历写回；医生始终是最终决策者。
